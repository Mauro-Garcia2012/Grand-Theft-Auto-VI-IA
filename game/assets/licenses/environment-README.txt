Realistic environment assets
============================

Textures (assets/textures) - CC0 1.0, ambientCG (https://ambientcg.com) and Poly Haven
(https://polyhaven.com), taken from the shared library of github.com/fable-cities:
  sand = Ground055S, grass = Grass004, dirt = Ground054, mud = Ground038, asphalt = Asphalt031,
  concrete = Concrete034, paving = PavingStones070, plaster = Plaster003, bricks = Bricks059,
  steel = CorrugatedSteel005, wood = Planks021, glass = Facade001 / Facade009, bark = Bark012,
  cwall = Poly Haven concrete_wall_008.

Street furniture (assets/props/city) - CC0 1.0, Poly Haven models: street_lamp_01,
  painted_wooden_bench, metal_trash_can, fire_hydrant, potted_plant_01, planter_box_01,
  concrete_road_barrier (via github.com/fable-cities), exterior_aircon_unit, utility_box_01
  (via github.com/WroclawTheGame). Decimated and textures resized with Blender.

Vegetation (assets/props/nature):
  - broadleaf.glb, bush.glb, hedge.glb: SpeedTree broadleaf tree and its leaf atlas from the
    Babylon.js Assets repository (github.com/BabylonJS/Assets, meshes/Trees), CC BY 4.0.
    Converted from .babylon to glTF; the bushes are built from the same leaf atlas.
  - palm_tall.glb, palm_curved.glb, palm_short.glb: made for this project in Blender; trunk
    texture derived from ambientCG Bark012 (CC0), frond texture painted procedurally.
